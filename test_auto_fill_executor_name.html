原订单执行人自动填充功能演示

📋 功能说明

当用户输入"原订单执行人账号"时，系统会自动查询用户信息：

  • 账号存在：自动填充"原订单执行人名称"字段
  • 账号不存在：提示手动填写名称
  • 账号为空：允许为空，清空名称字段

🧪 功能测试



原订单执行人名称，允许为空。如果账号存在会自动填充，否则请手动填写

✅ 成功场景

输入存在的账号：cnch_zmw01

预期结果：

  • 账号验证：✓ 账号有效：张三
  • 名称自动填充：张三
  • 提示：✓ 已自动填充

⚠️ 账号不存在场景

输入不存在的账号：nonexistent_user

预期结果：

  • 账号验证：✗ 账号 nonexistent_user 不存在，请检查后重试
  • 名称字段：清空
  • 提示：账号不存在，请手动填写名称

🔄 空值场景

清空账号字段

预期结果：

  • 账号验证：✓ 允许为空（原本可能就没有执行人）
  • 名称字段：清空
  • 提示：清除

❌ 网络错误场景

网络请求失败

预期结果：

  • 账号验证：验证失败，请稍后重试
  • 名称字段：不变
  • 提示：验证失败，请手动填写名称

🔧 技术实现

前端逻辑

// 监听账号输入
origExecutorInput.addEventListener("input", function () {
    const loginName = this.value.trim();
    
    if (!loginName) {
        // 清空名称字段
        origExecutorNameInput.value = '';
        return;
    }
    
    // 调用验证API
    fetch(`/order/executor/validate/?login_name=${loginName}`)
        .then(response => response.json())
        .then(data => {
            if (data.valid && data.user_name) {
                // 自动填充名称
                origExecutorNameInput.value = data.user_name;
            } else {
                // 清空名称，提示手动填写
                origExecutorNameInput.value = '';
            }
        });
});
